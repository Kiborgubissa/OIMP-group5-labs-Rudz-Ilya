# Лабораторная работа №4 — Поиск вхождений массива B в A

## Постановка задачи
Пользователь вводит два массива: A из n чисел и B из m
чисел. Нужно посчитать, сколько раз массив B встречается в A подряд.

## Как решал
Сначала спрашиваем n и m, проверяем что они больше 0 и что m не больше n
(иначе B в A влезть не может). Массивы выделяем через new, потому что n и m
заранее неизвестны.

Дальше идём по A с позиции 0 до n-m и для каждой смотрим: совпадает ли кусок
A[i..i+m-1] с B. Если хоть один элемент не совпал — прерываем внутренний
цикл и идём дальше. Если всё совпало — увеличиваем счётчик. В конце выводим
счётчик и освобождаем память.
