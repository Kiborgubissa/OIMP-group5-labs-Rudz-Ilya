# Лабораторная работа №3 — Одномерные массивы

## Постановка задачи
Задачу дал одногруппник — Зеков Антон (@Irishjdicof в тг).

Пользователь вводит размер массива n (не больше 100), потом
заполняет массив целых чисел, программа увеличивает каждый элемент в 2 раза
и выводит получившийся массив.

## Как решал
Сначала спрашиваем n и проверяем что оно от 0 до 100. Потом читаем первый
массив, потом второй. Дальше в цикле складываем поэлементно и сразу выводим
результат.
