# Лабораторная работа №2 — Прямоугольники

## Постановка задачи
Вывести в консоли N прямоугольников из символов * по заданным координатам,
ширине и высоте. Размер консоли
определяется автоматически, и чтобы прямоугольник точно влез — ввод
проверяется.

## Как решал
Сначала узнаём размер окна консоли, чтобы понять, в каких границах можно
рисовать. Для этого используем функции из windows.h: GetStdHandle получает
ручку консоли, GetConsoleScreenBufferInfo — информацию об окне. Из неё берём
ширину и высоту в символах.

Потом спрашиваем у пользователя координаты, ширину и высоту каждого
прямоугольника, проверяя что он влезет в окно (иначе программа попросит
ввести заново). Дальше чистим экран и рисуем каждый прямоугольник: верхняя
и нижняя линии — сплошные из *, боковые — по одной * слева и справа. Курсор
ставим в нужную точку через SetConsoleCursorPosition 
В задаче я ограничил количество прямоугольников от 1 до 10
