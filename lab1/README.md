# Лабораторная работа №1 — Ряды Тейлора

## Постановка задачи
Вычислить значение функции через ряд Тейлора с точностью ε = 10^(-k).
Значения x и k вводит пользователь.

Задачи:
1. sin(x) = x - x^3/3! + x^5/5! - ...
2. 1/sqrt(1+x) = 1 - x/2 + (1*3)/(2*4)*x^2 - ...   (x от -1 до 1)
3. arth x = x + x^3/3 + x^5/5 + ...                (x от -1 до 1)

## Как решал
Вводим x и k, считаем ε = 10^(-k). Дальше считаем члены ряда по очереди:
каждый следующий через предыдущий, чтобы не считать факториалы заново.
Складываем в сумму, пока модуль очередного члена не станет меньше ε.

В конце выводим сумму ряда и рядом значение из библиотеки cmath, чтобы
сравнить.

Для 1/sqrt(1+x) и arth x добавляем проверку x: он должен быть от -1 до 1.
