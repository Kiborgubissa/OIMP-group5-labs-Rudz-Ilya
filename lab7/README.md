# Лабораторная работа 7. Морской бой — консольная игра на C++

## О программе

Классический «Морской бой» для игры **человека против компьютера** в консоли.
У каждого игрока поле 10×10 и одинаковый флот из 10 кораблей (20 клеток).
Игрок может расставить свои корабли **вручную** или **случайно** (с возможностью
переброса), программа расставляет свои корабли случайно.

Реализовано правило **«попал — стреляй ещё раз»**: удачный выстрел даёт
дополнительный ход, промах передаёт ход противнику.

## Постановка задачи

1. Игрок расставляет свой флот: 1×4, 2×3, 3×2, 4×1 (всего 20 клеток).
   - Вручную — задавая начало и конец каждого корабля.
   - Случайно — с возможностью перебросить, пока расстановка не понравится.
2. Программа расставляет свои корабли случайно.
3. Игрок видит:
   - **своё поле** — с кораблями, попаданиями и промахами;
   - **поле противника** — только следы своих выстрелов (корабли скрыты).
4. Игрок и программа стреляют по очереди, вводя координаты вида `A5`, `J10`.
5. Побеждает тот, кто первым потопит **весь** флот противника.

## Правила игры

### Поле и координаты

- Поле 10×10 у каждого игрока.
- Строки — буквы **A…J** (ровно 10 букв).
- Столбцы — числа **1…10**.
- Имя клетки: буква + число, например `A1`, `C7`, `J10`.

### Флот

| Корабль | Длина | Количество |
|---------|-------|------------|
| Линкор | 4 | 1 |
| Крейсер | 3 | 2 |
| Эсминец | 2 | 3 |
| Катер | 1 | 4 |
| **Итого** | | **10 кораблей / 20 клеток** |

### Расстановка

- Корабль — прямая линия клеток: горизонтально или вертикально.
- Корабли **не касаются друг друга** — ни сторонами, ни углами.
  (Проверяются все 8 соседних клеток каждой палубы.)
- Корабли не выходят за границы поля и не накладываются друг на друга.

### Ход игры

- Игроки ходят **по очереди**.
- Ход = один выстрел по клетке поля противника.
- Ответ на выстрел:
  - **Промах** — клетка пустая;
  - **Попадание** — попал в корабль.
- **Попал → стреляй ещё раз.** Промах → ход переходит к противнику.
- В клетку, куда уже стреляли, повторно стрелять нельзя.

### Победа

Побеждает тот, кто **первым потопит весь флот противника** —
все 10 кораблей, все 20 клеток. Просто «много попаданий» — не победа.

## Как играть

После запуска программа спросит, как расставить флот:

```
Как расставить ваш флот?
  1 — вручную
  2 — случайно
Выбор:
```

### Вариант 1 — вручную

Для каждого корабля вводите **две координаты через пробел**: начало и конец.

| Ввод | Корабль |
|------|---------|
| `B2 B5` | 4-палубный, B2 → B5 (горизонтально) |
| `D1 A1` | 4-палубный, A1 → D1 (вертикально) |
| `H8 H8` | 1-палубный, клетка H8 |

Если что-то не так — программа объяснит и попросит повторить ввод
текущего корабля (без перезапуска игры). Проверяется:
- формат координат (буква A–J, число 1–10);
- горизонтальность/вертикальность;
- совпадение длины с ожидаемой;
- отсутствие касаний с другими кораблями.

### Вариант 2 — случайно

Программа сгенерирует расстановку и покажет её:

```
[Enter — принять, r — перебросить]:
```

- **Enter** — принять и начать игру.
- **`r`** — сгенерировать заново.

### `struct Board` — игровое поле

- `char g[N][N]` — матрица символов.
- `clear()` — очистить поле.
- `canPlace(r, c, len, horiz)` — можно ли поставить корабль, не задев
  границ и не коснувшись других (проверяются 8 соседей каждой палубы).
- `placeShip(r, c, len, horiz)` — поставить корабль.
- `generateRandom(rng)` — случайная расстановка всего флота.
- `remainingShips()` / `allSunk()` — сколько ещё не подбитых клеток / весь ли флот потоплен.
- `print(showShips, title)` — отрисовка поля. `showShips = false` скрывает корабли
  (для поля противника).

### `attack()` — общая функция атаки

Используется **и игроком, и программой**: обе стороны стреляют одинаково,
различается только то, **кто выбирает координату**. Возвращает один из
`Result`-результатов.

### Ввод / утилиты

- `parseCoord(s, r, c)` — разбор `"A5"`, `"b 7"`, `"J10"`.
- `cellName(r, c)` — обратное преобразование `(0, 0) → "A1"`.
- `trim(s)`, `splitWords(s)` — вспомогательные функции для парсинга строки.

### `setupManual(Board&)` / `setupRandomInteractive(Board&, rng)`

Два способа расставить **свой** флот. Программа использует
`Board::generateRandom` напрямую.

### `struct AI` — стратегия программы

- `tried` — множество клеток, куда уже стреляли.
- `pending` — «подозрительные» клетки рядом с попаданиями.
- `choose()` — выбор следующей цели:
  1. если есть `pending` — берёт из него (добивает корабль);
  2. иначе — случайная непроверенная клетка.
- `onHit(r, c)` — при попадании добавляет четырёх соседей в `pending`.

### `main()` — игровой цикл

```
пока никто не победил:
    если ход игрока:
        показать поля
        спросить координату
        attack(enemy, ...)
        если попал → стреляет снова
        иначе    → ход переходит программе
    иначе:
        AI выбирает координату
        attack(player, ...)
        если попал → AI::onHit, стреляет снова
        иначе    → ход переходит игроку
```

## Возможные улучшения

- **Умный ИИ** — шахматный поиск (стрелять по чётным клеткам), добивание
  вдоль линии после двух попаданий, вычёркивание соседей вокруг потопленного
  корабля. Существенно уменьшает среднее число выстрелов.
- **Отметка клеток вокруг потопленного корабля** — сейчас этого нет, потому что
  в `Board` не хранится информация о том, какие клетки принадлежат одному кораблю.
  Понадобится добавить `vector<Ship>` внутрь `Board` (как в «компьютер против
  компьютера» версии).
- **Сохранение партии** в файл — чтобы можно было продолжить позже.
- **Статистика** в конце партии — сколько ходов сделал каждый, сколько попаданий,
  процент точности.
- **Улучшение визуала** — ANSI-цвета для попаданий/промахов, рамки, анимации.
